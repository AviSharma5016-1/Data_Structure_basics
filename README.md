📘 Program 1: helloworld.cpp
🔍 AIM:
To write a simple C++ program that displays the message “Hello, World!” on the screen.

📖 Theory:
The "Hello, World!" program is traditionally the very first program written by students when learning a new programming language. While it may appear trivial, it plays an important role — it introduces the fundamental structure of a C++ program and tests whether the development environment (compiler, editor, etc.) is set up correctly.

In C++, the program begins with the #include<iostream> directive which allows the use of input-output functionalities. The function int main() serves as the entry point of the program. Inside the main() function, std::cout is used to display output to the console. The statement ends with return 0;, indicating that the program executed successfully.

This program teaches:

Basic syntax

Header inclusion

Use of main() function

Standard output using cout

Compilation and execution flow

✅ Conclusion:
The program was successfully compiled and executed. The output “Hello, World!” was displayed on the screen, confirming that the C++ environment was set up correctly. Through this exercise, we understood the basic structure of a C++ program and familiarized ourselves with standard output commands. This simple exercise lays the groundwork for writing more complex programs in the future.

📘 Program 2: calculator.cpp
🔍 AIM:
To develop a basic calculator using C++ that performs arithmetic operations such as addition, subtraction, multiplication, and division based on user input.

📖 Theory:
A calculator is a foundational program in programming, helping students learn how to take user input, process logic based on conditions, and return appropriate output. In this program, we use the switch-case control structure, which evaluates a user-selected operation and performs the corresponding arithmetic calculation.

The program begins by taking two numbers as input from the user and then prompts the user to choose an operation (+, -, *, /). The selected operation is passed to a switch statement, which determines the flow of execution. Each case performs the respective operation and displays the result. The default case is used to handle invalid inputs gracefully.

This program demonstrates:

Input/output handling using cin and cout

Conditional branching using switch

Type-safe arithmetic operations

Basic program structure and user interaction

✅ Conclusion:
The calculator program was successfully implemented. It accepted user inputs, evaluated the chosen operation, and returned the correct result. This hands-on program helped reinforce key concepts such as control structures (switch-case), input/output, and basic error handling. It marked a crucial step in developing interactive and logic-based applications, building a strong foundation for future programming challenges.
